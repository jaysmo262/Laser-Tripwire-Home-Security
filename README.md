# Laser-Tripwire-Home-Security
Laser activated home security system that sounds buzzer when alerted. 
##features
-Laser tripwire detection
-Audible alarm
-Low cost design
-simple and expandable circuit
## components
-Arduino Umo Q
-Laser module
-Photoresistor
-10kohm resistor
-piezo buzzer
-breadboard
-Jumper wires
## How it works
A laser continuously shines into the photoresistor. The photoresistor monitors the light level that is being shone into it. If the beam is broken the light level will drop, and the arduino will immedietly alert and sound the buzzer.
## Future improvements 
-Phone notifications
-Wireless communication
-Battery Backup
-Keypad arm/disarm system
